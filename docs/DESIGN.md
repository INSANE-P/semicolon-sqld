# 설계 메모

시험까지 사흘, 처음 보는 범위. 이 조건에서 점수가 가장 많이 오르는 방식으로 화면을 정했다.

## 공부 방식

- **읽고 바로 푼다.** 다시 읽기보다 한 번 꺼내 써 보는 쪽이 오래 남는다(인출 연습, Roediger & Karpicke 2006). 문제를 장 끝에 붙였고, 고르면 바로 해설이 나온다. 본문 중간에도 눌러야 답이 보이는 질문을 넣었다.
- **틀린 것은 알아서 모인다.** 사흘이면 간격을 길게 벌릴 수 없어서 틀린 문제만 다시 돌게 했다. 오답 노트에서 맞히면 빠지고 틀리면 남는다. 문제는 안 풀어 본 것, 틀린 것, 맞힌 것 순서로 뽑는다.
- **섞어서 푼다.** 장별로만 풀면 "지금 이 장이니까"라는 단서로 맞히게 된다. 섞어서 10문제와 모의고사는 어떤 규칙을 쓸지부터 고르게 한다(교차 연습, Rohrer & Taylor 2007).
- **예시 먼저.** 정의보다 작은 표와 SQL, 결과를 먼저 보여 준다. 결과를 묻는 문제가 시험의 3분의 1을 넘는다.
- **바로 알려 준다.** 한 문제씩 풀 때는 고르는 순간 아래에서 해설이 올라오고, 맞히면 꽃가루, 틀리면 흔들림으로 결과를 몸으로 먼저 알린다. 해설을 읽어야 다음으로 넘어간다.

## 브랜드: 세미콜론

- **이름.** SQL 문장 끝에 붙는 세미콜론(;)에서 따왔다.
- **마크.** 파란 타일 위 노란 점과 흰 쉼표. 아래에 두께를 줘서 화면의 통통한 버튼과 같은 모양 말을 한다.
- **글자 로고.** 글꼴을 쓰지 않고 선으로 직접 그렸다(`assets/app.js` 의 `WORD`). 굵기 6.6, 둥근 끝. 겹친 글자(콜, 론)는 받침이 뭉치지 않게 줄 간격을 넓혔다.
- **마스코트.** 세미콜론 모양 캐릭터. 기분은 넷(기쁨, 환호, 시무룩, 졸림)과 생각 하나. 맞히면 환호, 틀리면 시무룩, 빈 화면은 졸림.
- **색.** 파랑 `#3B5BFD`(주색), 해바라기 `#FFC93C`(누르는 곳, 강조), 먹색 `#121A33`(글자), 바탕 `#F4F6FB`. 정답 초록 `#169C5A`, 오답 빨강 `#F03E3E` 는 주색과 겹치지 않게 따로 둔다.
- **장 갈래 색.** 1과목 청록, SQL 기본 파랑, SQL 활용 보라, 관리 구문 주황. 장 번호 배지, 왼쪽 띠, 소제목 막대에 같이 쓴다.
- **글꼴.** 본문은 Pretendard, 제목과 숫자는 G마켓 산스, 코드는 JetBrains Mono.
- 시안 네 개(체크 세미콜론, 말풍선, 통통 타일, 책갈피 노트) 가운데 통통 타일을 골랐다. 버튼과 결이 같고 가장 서비스다운 색이라서.

## 화면

- 본문 폭은 한 줄 40자 안팎, 줄 간격 1.78.
- 누르는 것(버튼, 보기)은 아래에 두께가 있고 누르면 들어간다. 읽는 것(본문, 표)은 평평하다.
- 빨강은 함정과 오답에만, 노랑은 강조와 시험 직전 요약에만 쓴다. 형광펜은 한 문단에 한 번.
- 휴대폰은 아래 떠 있는 탭, 책상은 왼쪽 목차. 장을 읽을 때는 맨 위에 읽은 만큼 막대가 찬다.
- 밝은 화면과 어두운 화면 둘 다. 움직임 줄이기 설정을 켜면 움직임을 모두 끈다.
- 한 번 열어 두면 인터넷 없이도 열리고, 홈 화면에 앱처럼 깔 수 있다.

## 모의고사 구성

1과목은 장마다 한 문제씩 10문항. 2과목 40문항은 예상 문제 250문항에서 센 주제별 비중을 따랐다
(함수 5, 서브쿼리 5, GROUP BY 3, 표준 조인 3, DDL 3, 나머지 1~2).

## 접근성

- axe 검사(WCAG 2.2 AA와 권장 사항)를 휴대폰과 책상 폭, 밝은 화면과 어두운 화면에서 화면 12종에 돌려 위반 0건으로 맞췄다.
- 글자는 바탕과 4.5:1 이상. 흐린 회색, 장 갈래 색, 정답과 오답 버튼 색, 코드 주석색을 이 기준으로 다시 잡았다.
- 출제 비중 별은 글자가 아니라 그림이고, 화면 읽기 프로그램에는 "출제 비중 3/3, 거의 매회 나와요"로 읽힌다.
- 키보드만으로 다 쓸 수 있다. 첫 Tab 은 "본문으로 건너뛰기", 화면이 바뀌면 새 제목으로 초점이 간다. 문제를 고르면 채점 결과 제목으로, 계속하기 뒤에는 다음 문제 제목으로 간다.
- 휴대폰에서 닫힌 목차는 건너뛰고, 열면 초점이 목차 안으로, Esc 로 닫으면 메뉴 버튼으로 돌아온다.
- 가로로 넘치는 표와 그림, SQL 은 초점을 받아 화살표로 밀 수 있다. 그림에는 설명을 이름으로 붙였다.
- 현재 위치는 aria-current, 눌린 상태(날짜, 카드 묶음, 카드 뒤집기)는 aria-pressed 로 알린다.
- 움직임 줄이기 설정을 켜면 꽃가루와 움직임을 모두 끈다.

## 링크 미리보기

`assets/og.png`(1200×630)와 Open Graph, 트위터 카드 태그를 넣었다. 카카오톡, 슬랙, 디스코드에 주소를 붙이면 간판 그림이 뜬다.

## 휴대폰에서 읽기

360px 폭에서 30개 장을 모두 열어 옆으로 넘치는 상자를 셌다(SQL 256개 중 155개, 그림 41개 전부, 데이터 표 13개, 설명 표 5개). 옆으로 미는 일을 없애는 쪽으로 바꿨다.

- **SQL** 은 줄을 접는다. 접힌 줄은 원래 들여쓰기보다 두 칸 더 들어가서 이어진 줄인 게 보인다. 넘치는 코드 0개.
- **칸이 셋 이상인 설명 표**는 줄마다 카드로 쌓는다. 첫 칸이 카드 제목, 나머지는 "칸 이름: 값"으로. 넘치는 표 0개.
- **그림**은 폭에 맞추고, 누르면 화면 가득 크게 본다. 크게 보기에서는 옆으로 밀거나 두 손가락으로 키울 수 있고 Esc 나 바깥을 누르면 닫힌다.
- **넓은 데이터 표**(결과 칸이 많은 것)는 첫 칸을 고정하고, 더 밀 게 있으면 오른쪽 끝이 흐려진다. 4개 남았고 모두 이 방식이다.
- 휴대폰에서는 여백과 칸 안쪽 간격을 줄여 본문 폭을 넓혔다.

## 사람 손이 간 화면으로(2차)

"AI 가 만든 화면 같다"는 말을 듣는 모양을 걷어냈다.

- **그라데이션을 뺐다.** 첫 화면 큰 카드, 목차의 D-day, 읽기 막대, 진행 막대, 카드 뒷면, 설치 안내, 장 머리의 빛 번짐까지 모두 단색이다. 남은 건 형광펜과 소제목 막대처럼 경계가 딱 떨어지는 두 색, 넘치는 표 끝을 흐리게 하는 표시, 그림 뒤 점 무늬뿐이다.
- **색 사각형 아이콘 타일을 줄였다.** 첫 화면 숫자 네 개는 한 줄 표로, 문제 고르기 네 카드는 목록으로, 처음 안내 네 카드는 접히는 글로 바꿨다.
- **꾸밈을 뺐다.** SQL 상자의 맥 창 점 세 개, 누를 수 없는 학습 목표 체크 상자(번호로 바꿈), 요약 칸의 테이프, 장 머리의 마스코트, 그림 설명의 "그림" 꼬리표.
- **아이콘은 한 뜻에 한 모양.** 모의고사는 체크 클립보드, 정답률은 원그래프, 오늘 할 일은 체크 달력, 인쇄는 프린터. 시계는 시간에만, 과녁은 쓰지 않는다.
- **가운뎃점과 긴 줄표를 쓰지 않는다.** 화면 문구와 본문 모두. 본문은 해요체로 맞췄다(합쇼체 500여 곳).
- 화면 문구는 Codex 검토를 거쳤다. "오답 노트 비우기" 같은 비유를 하는 일로 바꾸고, 과락 기준 문장을 "16개보다 적게 맞히면"으로 고쳤다.

## 날짜 고르기

입력창 대신 달력이다. 휴대폰은 아래에서 올라오는 판, 책상은 가운데 작은 창. 오늘 전 날짜는 고를 수 없고, 고른 날짜와 D-day 가 위에 바로 보인다. 화살표로 날짜, Page Up/Down 으로 달을 넘기고, 휴대폰은 달력을 옆으로 밀어 달을 넘긴다.

## 찾기

<kbd>/</kbd> 나 위쪽 돋보기로 연다. 장 제목, 소제목, 시험 직전 요약, 암기 카드에서 띄어쓰기와 대소문자를 가리지 않고 찾고, 누르면 그 소제목이나 요약 자리로 바로 가서 잠깐 노랗게 표시한다.

## 시험 회차 고르기

2027년 일정은 아직 공고 전이다(보통 12월 말에서 1월 사이에 나온다). 2026년 회차(3/7 토, 5/31 일, 8/22 토, 11/14 토)와 같은 흐름으로 2027년 날짜를 짐작해 `content/_meta.js` 의 `exams` 에 넣고 `sure: false` 로 표시했다. 화면에는 "예상" 꼬리표와 공식 사이트 링크가 함께 나온다. 공고가 나오면 날짜를 고치고 `sure` 를 true 로 바꾼다.

- 시험이 지나면 첫 화면이 계획 대신 다가오는 회차 단추를 보여 준다. 누르면 바로 그 날짜로 정하고 계획을 오늘부터 다시 나눈다.
- 달력 창 위에도 같은 단추가 옆으로 미는 한 줄로 있고, 달력 안 시험 날에는 노란 점이 찍힌다.

## 읽기와 카드(3차)

- **장 차례**: 목표 아래에 소제목 목록을 둔다. 책상에서는 펼쳐 두고 휴대폰에서는 접어 둔다. 누르면 그 소제목으로 가서 잠깐 노랗게 표시한다.
- **이어 읽기**: 스크롤하며 지나간 마지막 소제목을 장마다 기억한다. 다시 들어오면 "지난번에 ... 부분까지 읽었어요" 띠와 이어 읽기 단추가 나온다.
- **글자 크기**: 작게, 보통, 크게. 본문, 표, 코드, 문제, 카드 글자가 함께 바뀐다.
- **카드**: 장 하나만 골라 볼 수 있고(장 순서대로), 카드 높이는 앞뒤 중 긴 쪽에 맞춘다. 알았어요와 몰랐어요 수, 방금 것 되돌리기, 그 카드가 나온 장으로 가는 링크를 둔다. 휴대폰에서는 뒤집은 다음 오른쪽으로 밀면 알았어요, 왼쪽이면 몰랐어요.

## 만든 사람과 평 남기기

- 입구는 목차 맨 아래와 첫 화면 맨 아래의 작은 "만든 사람" 링크 둘뿐이다. 공부하는 화면에는 끼어들지 않는다.
- 소개는 공개 깃허브 프로필에 있는 것(이름, 아이디)과 이 사이트를 만든 이유만 쓴다.
- 평은 giscus 로 저장소 Discussions 의 Announcements 분류에 있는 글 하나("세미콜론 평 남기기")에 모인다. 이 분류는 새 글을 저장소 주인만 열 수 있어서 엉뚱한 글이 생기지 않는다. 댓글 창은 그 페이지를 열 때만 불러오고, 밝은 화면과 어두운 화면을 따라간다.
- 오프라인 저장은 글꼴만 한다. 댓글과 프로필 사진은 늘 새로 받는다.

## 숨은 것

만든 사람 페이지에 몇 개 찾았는지만 보여 주고 찾는 법은 적지 않는다.

1. 첫 화면 마스코트를 빠르게 다섯 번 누르기
2. 키보드로 위 위 아래 아래 왼쪽 오른쪽 왼쪽 오른쪽 B A
3. 찾기에 "세미콜론" 이나 ";" 치기
4. 만든 사람 사진을 세 번 누르기(마스코트로 뒤집힌다)

개발자 도구 콘솔에도 저장소 주소를 남겼다.

## 평이 올라온 순간

giscus 의 `emit-metadata` 로 평 수를 받는다. 처음 받은 수를 기준으로 두고 늘어나면 방금 올라온 것으로 본다.

- 평 칸 오른쪽 위 모서리에 마스코트가 걸터앉아 가끔 들썩인다. 누르면 한마디 한다.
- 평이 올라오면 마스코트가 환호하며 뛰고, 말풍선, 칸 테두리 노란 빛, 꽃가루가 함께 나온다. 제목 옆 "평 n개"가 튀어 오르며 하나 늘어난다.
- 한 번 남긴 사람에게는 제목 아래 안내가 "남겨 준 평 잘 받았어요"로 바뀐다. 같은 수가 다시 와도 두 번 축하하지 않는다.
